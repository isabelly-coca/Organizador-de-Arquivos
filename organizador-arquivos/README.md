# 📁 Organizador de Arquivos

Projeto desenvolvido em Python para organizar automaticamente arquivos por categoria.

## Tecnologias

- Python 3
- pathlib
- shutil

## Funcionalidades

- Organiza automaticamente arquivos
- Cria pastas caso não existam
- Gera log das movimentações
- Categoria "Outros"
- Fácil de adicionar novas categorias

## Como executar

python main.py
